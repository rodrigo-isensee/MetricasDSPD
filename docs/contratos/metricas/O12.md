## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | responsabilidade-atraso |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 O12; 7.3 classificação no vencimento |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `compromissos`: Acordos e vencidos (`o12`).
