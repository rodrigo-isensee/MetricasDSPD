## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | faixa-idade, severidade |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | 06 O16; 4.4 origem_bug |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `qualidade-compl`: Estoque e idade de bugs (`o16`).
