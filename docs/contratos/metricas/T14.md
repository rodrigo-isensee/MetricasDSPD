## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | nenhuma |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | pedido 011 T14; Q-T14-1 = B (campo "Time responsável" do card), Q-T14-5 = D (projetos ligados a sistema do meu time, mesmo com 0%, mais os com 1 ou mais card do meu time), Q-T14-9 = A (usuário, provisória até confirmar a cardinalidade do campo), Q-T14-10 = B (decidida pelo usuário: cadastro de membros por time; no mock, simulado, na fase 3 vem da configuração) e T14-M1 = B (com outros times oculto, só a fatia do meu time, sem total nem n; K-130), Q-T14-6 = A revista pela R-1 = B (outros times é um inteiro só, sem nome, tempo, vazão nem ranking, e fica oculto quando somar menos de 2 pessoas); o filtro de equipe só diz qual é "meu time" e não recorta a população; exige exatamente uma equipe (CA-28); ordem dos visíveis pelo total de cards (CA-30) e, depois deles, os ocultos por código (Q-T14-12 = B, decidida pelo usuário em 2026-10-28); total do bloco e base só dos visíveis; percentual só com 20 ou mais cards com time informado (CA-31) |
| Status | pendente-usuario |

Status `pendente-usuario`: há célula de regra que o briefing não responde. Não se infere no código: é pergunta ao usuário (ver `docs/architecture/regras-metricas.md`).

## Cartões que usam a métrica

- Painel `tatico`, seção `de-quem-depende-o-prazo`: Participação do meu time no projeto (`t14`).
