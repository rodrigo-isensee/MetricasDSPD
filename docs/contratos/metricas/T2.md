## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | classe-servico, etapa |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 T2; Q3 |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `publicado`: Aderência ao SLE (`t2`).
