## Rota

`GET /api/v1/metricas/S5` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

| Parâmetro | Tipo | Obrigatório | Detalhe |

| `equipe` | string | não |  |
| `prioridade` | string | não |  |

| `de` | string | não | formato: date |

| `dataReferencia` | string | não | formato: date |

## Filtros

- Atuam nesta métrica: equipe, prioridade, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | motivo-escalacao |
| Ordem | neutra |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 S5; 7.3 domínio fechado |
| Status | ok |

## Cartões que usam a métrica

- Painel `sustentacao`, seção `causas`: Motivos da escalação (`s5`).
