## Filtros

- Atuam nesta métrica: equipe, prioridade, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | sistema |
| Ordem | neutra |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 S12 |
| Status | ok |

## Cartões que usam a métrica

- Painel `sustentacao`, seção `sust-o-que-entra`: Volume por sistema (`s12`).
