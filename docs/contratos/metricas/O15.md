## Rota

`GET /api/v1/metricas/O15` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

| `de` | string | não | formato: date |

| `dataReferencia` | string | não | formato: date |

## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | fase-deteccao |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 O15; 4.3 bug/defeito; 4.2 janela 30 d; 7.2 |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `qualidade`: Onde os bugs são encontrados (`o15`).
