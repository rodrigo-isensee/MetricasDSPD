## Rota

`GET /api/v1/metricas/T3` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | natureza-alocacao |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 T3; 4.3 natureza; P8 (UX, provisória) |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `fila`: Alocação da capacidade (`t3`).
