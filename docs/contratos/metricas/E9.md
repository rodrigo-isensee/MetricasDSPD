## Filtros

- Atuam nesta métrica: sistema, periodo.
- Não atuam: equipe, tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | projeto |
| Segmentação permitida | tipo-projeto |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | referencia-percentil |
| Referência no briefing | pedido 011 E9; R-6 (criado_em = aprovação); referência P85 por tipo de projeto (regra 7, Q4) importada do E1 |
| Status | ok |

## Cartões que usam a métrica

Nenhum cartão do catálogo usa esta métrica diretamente.
