## Filtros

- Atuam nesta métrica: equipe, prioridade, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | tipo-reclassificacao |
| Ordem | temporal |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 S7 (medidos separadamente) |
| Status | ok |

## Cartões que usam a métrica

- Painel `sustentacao`, seção `causas`: Reclassificação (`s7`).
