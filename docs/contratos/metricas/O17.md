## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | causa-raiz, sistema |
| Ordem | neutra |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | 06 O17; 4.4 causa raiz |
| Status | ok |
