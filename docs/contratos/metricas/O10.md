## Rota

`GET /api/v1/metricas/O10` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

| Parâmetro | Tipo | Obrigatório | Detalhe |
|---|---|---|---|
| `equipe` | string | não |  |
| `tipo` | string | não |  |
| `sistema` | string | não |  |
| `periodo` | string | não | valores: 4s, 12s, 6m, 12m, custom; padrão: 12s |
| `de` | string | não | formato: date |
| `ate` | string | não | formato: date |
| `dataReferencia` | string | não | formato: date |
| `page` | integer | não |  |
| `pageSize` | integer | não |  |

## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo, faixa-idade |
| Ordem | neutra |
| Inclui arquivados | pendente-usuario |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis |
| Referência no briefing | 06 O10; 4.1 entrada/compromisso |
| Status | pendente-usuario |

Status `pendente-usuario`: há célula de regra que o briefing não responde. Não se infere no código: é pergunta ao usuário (ver `docs/architecture/regras-metricas.md`).

## Cartões que usam a métrica

- Painel `operacional`, seção `backlog`: Envelhecimento do backlog (`o10`).
