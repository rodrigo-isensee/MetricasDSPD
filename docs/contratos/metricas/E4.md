## Filtros

- Atuam nesta métrica: sistema, periodo.
- Não atuam: equipe, tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | projeto |
| Segmentação permitida | tipo-projeto |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | 06 E4 |
| Status | ok |

## Cartões que usam a métrica

- Painel `estrategico`, seção `terminando-ou-comecando`: Iniciadas × concluídas (`e4`).
