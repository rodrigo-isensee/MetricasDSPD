## Filtros

- Atuam nesta métrica: sistema, periodo.
- Não atuam: equipe, tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | sistema, natureza-alocacao |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | pedido 011 E7; D2 = A (2026-10-17, pedido 024): participação percentual de cada sistema pelas entregas do período, sem R$ (revê a D-1' e a Q-E7-1); D-2 (peso por contagem de entregas); percentual só para sistema com 20 ou mais entregas, abaixo disso "k de n"; CA-23 (naturezaDe do T3) |
| Status | ok |

## Cartões que usam a métrica

- Painel `estrategico`, seção `concentracao-do-parque`: Capacidade por sistema (`e7`).
