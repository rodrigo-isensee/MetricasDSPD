## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | classe-servico, etapa |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, mediana |
| Referência no briefing | 06 T1; Q3 |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `publicado`: Lead time ponta a ponta (`t1`).
