## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo, relogio |
| Ordem | temporal |

| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, mediana |
| Referência no briefing | 06 O9; 4.1 |
| Status | ok |
