## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | mediana |
| Referência no briefing | 06 O5; 4.1 inicio; 4.2 bloqueio |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `por-que-demora`: Eficiência de fluxo (`o5`).
