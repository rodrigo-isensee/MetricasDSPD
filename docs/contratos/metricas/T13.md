## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa, percentis |
| Referência no briefing | pedido 011 T13; D-14' = A (só vínculo predecessor com card de outro quadro, CA-40; pai/filho fora, CA-21) e R-4 = sim (vigente em algum momento antes da entrega); granularidade story ou frente, um bloco cada (CA-8); quadro desconhecido vai para semDado; par com x sem do lead time do T1, por tipo e com 20 em cada grupo (CA-6); só o booleano, nunca o quadro nem a equipe do outro lado |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `de-quem-depende-o-prazo`: Dependências entre quadros (`t13`).
