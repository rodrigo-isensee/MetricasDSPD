## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo, faixa-passagens |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, taxa |
| Referência no briefing | pedido 011 O26; D-5' = B (troca = alguém sai e outro entra, ou o conjunto é substituído; incluir co-responsável não conta, CA-38); Q-a = 1 passagem (uma por revisão) e Q-b = conta (com o card sem responsável no meio compara com o último conjunto não vazio), decididas em 2026-10-16; só o inteiro passagens chega à biblioteca (ADR 0020); histograma sempre, percentual e P85 do ciclo por faixa com 20 ou mais |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `onde-perde-esforco`: Passagens de mão (`o26`).
