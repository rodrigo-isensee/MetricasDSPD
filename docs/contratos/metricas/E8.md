## Filtros

- Atuam nesta métrica: periodo.
- Não atuam: equipe, tipo, sistema.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | nenhuma |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | pedido 011 E8; D-3 = A (janela de 12 meses); R-1 = B (só a contagem de sistemas por faixa, sem nome de sistema nem de pessoa); recorte de menos de 5 sistemas não abre as faixas (CA-10); a faixa por sistema vem do agregado (ADR 0020), censo sem percentil |
| Status | ok |

## Cartões que usam a métrica

- Painel `estrategico`, seção `custo-do-parque`: Concentração de conhecimento (`e8`).
