## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | frente |
| Segmentação permitida | projeto |
| Ordem | temporal |
| Inclui arquivados | pendente-usuario |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, referencia-percentil |
| Referência no briefing | 06 T7; 02 feature = pacote; 7.3 granularidade; P2 (aging é eixo de tempo) |
| Status | pendente-usuario |

Status `pendente-usuario`: há célula de regra que o briefing não responde. Não se infere no código: é pergunta ao usuário (ver `docs/architecture/regras-metricas.md`).

## Cartões que usam a métrica

- Painel `tatico`, seção `projetos`: Fluxo de frentes (`t7`).
