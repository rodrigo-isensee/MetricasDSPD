## Rota

`GET /api/v1/metricas/S3` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

| Parâmetro | Tipo | Obrigatório | Detalhe |
|---|---|---|---|
| `equipe` | string | não |  |
| `prioridade` | string | não |  |
| `periodo` | string | não | valores: 4s, 12s, 6m, 12m, custom; padrão: 12s |
| `de` | string | não | formato: date |
| `ate` | string | não | formato: date |
| `dataReferencia` | string | não | formato: date |

## Filtros

- Atuam nesta métrica: equipe, prioridade, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | prioridade |
| Ordem | temporal |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | 06 S3 |
| Status | ok |

## Cartões que usam a métrica

- Painel `sustentacao`, seção `volume`: Volume mensal por prioridade (`s3`).
