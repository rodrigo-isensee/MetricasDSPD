`GET /api/v1/metricas/T6` (contrato completo de erros, cabeçalhos e cache: [http.md](../http.md); OpenAPI: [openapi.json](../../api/openapi.json)).

| `de` | string | não | formato: date |

| `pageSize` | integer | não |  |

## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | prioridade-bm |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis |
| Referência no briefing | 06 T6; T2.5 Monte Carlo |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `quando-fica-pronto`: Previsão probabilística (`t6`).
