## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa, percentis |
| Referência no briefing | pedido 011 O21; transicoes de retorno ate a conclusao; ciclo do O3 (entreguesDe); par com x sem so dentro do tipo, 20 em cada grupo (regra 7, CA-6); matriz por coluna (uma equipe) ou por papel (R5) |
| Status | ok |

## Cartões que usam a métrica

Nenhum cartão do catálogo usa esta métrica diretamente.
