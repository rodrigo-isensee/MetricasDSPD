## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | tipo |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, mediana |
| Referência no briefing | 06 O8; 7.2 nunca média isolada |
| Status | ok |

- Painel `operacional`, seção `por-que-demora`: Tamanho das demandas (`o8`).
