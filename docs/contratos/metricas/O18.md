## Filtros

- Atuam nesta métrica: equipe, sistema, periodo.
- Não atuam: tipo.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | com-sem-bug, tipo |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 O18; 4.2 janela 30 d |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `qualidade`: Entregas com e sem bug (`o18`).
