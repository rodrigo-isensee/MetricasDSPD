## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | coluna, tipo |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | 06 O1; 4.2 colunas; 7.3 fila conta WIP |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `diaria`: Trabalho em progresso e limite (`o1`).
