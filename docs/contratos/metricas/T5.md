## Filtros

- Atuam nesta métrica: equipe, tipo, periodo.
- Não atuam: sistema.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | sistema, area |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | taxa |
| Referência no briefing | 06 T5; 4.2 janela 30 d |
| Status | ok |

## Cartões que usam a métrica

- Painel `tatico`, seção `publicado`: Demanda de falha (`t5`).
