## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | classe-servico |
| Ordem | temporal |
| Inclui arquivados | true |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | referencia-percentil |
| Referência no briefing | 06 O6; mesma amostra do O3 |
| Status | ok |
