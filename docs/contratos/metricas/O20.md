## Filtros

- Atuam nesta métrica: equipe, tipo, sistema, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | businessmap |
| Granularidade | story |
| Segmentação permitida | nenhuma |
| Ordem | neutra |
| Inclui arquivados | true |
| Mínimo de amostra | 0 (contagem, censo ou retrato: sem mínimo) |
| Partes sob mínimo | nenhuma |
| Referência no briefing | pedido 011 O20; varredura +1/-1 por coluna do O1 (B8); faixa por coluna (uma equipe) ou por papel (R5); contagem diaria, sem estatistica |
| Status | ok |

## Cartões que usam a métrica

- Painel `operacional`, seção `onde-acumula`: Fluxo cumulativo (`o20`).
