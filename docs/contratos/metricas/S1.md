- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | prioridade |
| Ordem | temporal |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, mediana |
| Referência no briefing | 06 S1; 3.2; Q2 |
| Status | ok |

## Notas

- `horasPorDiaUtil` (D3b do pedido 099, Decisão 13): horas do dia útil do calendário usado no cálculo (8,8 na Sustentação, 528 min). A web converte horas em dias úteis por este número, sem constante própria. Campo novo e sempre enviado: mudança aceita no gate de contrato (ver `docs/contratos/politica-de-mudanca.md`, §2).
- Os alvos em dias do PROC passam a dias x 8,8 h (P3 restauração 17,6 h, P4 44 h, P5 8,8 h e 88 h) e o calendário do Acelerato passa a ter turnos gravados em `ref_calendario_turno`; as duas trocas têm versão de critério (T2.6) citando a Decisão 13.
