## Filtros

- Atuam nesta métrica: equipe, prioridade, periodo.
- Não atuam: nenhuma.

## Regras de cálculo

| Campo | Valor |
|---|---|
| Domínio | acelerato |
| Granularidade | chamado |
| Segmentação permitida | prioridade |
| Ordem | temporal |
| Inclui arquivados | nao-se-aplica |
| Mínimo de amostra | 20 itens por classe |
| Partes sob mínimo | percentis, mediana |
| Referência no briefing | 06 S1; 3.2; Q2 |
| Status | ok |

## Cartões que usam a métrica

- Painel `sustentacao`, seção `prazos`: Primeiro atendimento e restauração (`s1`).
