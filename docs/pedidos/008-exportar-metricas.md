# Pedido 008 — Exportar métricas em PDF ou imagem

Solicitante: Rodrigo Isensee · Data: 2026-10-10 · Registrado pelo Jarvis
## Objetivo
Permitir extrair **uma ou mais métricas** em **PDF ou imagem** para compartilhar uma visão exatamente como a pessoa está vendo (surgiu na validação do pedido 007: o link compartilhado leva só os filtros).
## Restrições
O arquivo exportado carrega o que a tela tem de obrigatório: base amostral, janela, "amostra insuficiente", nota metodológica resumida, marcação de mudança de critério e, no mock, o aviso de dados fictícios. Nada por pessoa.
## Fluxo
Discovery UX + arquiteto → protótipo → validação do usuário → entrega.
