# Pedido 070: dado simulado por cartão onde ainda não há dado real

- **Modo:** implementar
- **Objetivo:** cada cartão de métrica mostra o dado real quando ele existe e, quando não existe, o dado simulado com o selo "Simulado" bem visível; o selo some quando o dado real chega
- **Clareza:** 4 confirmado; 1 técnico; 0 suposição; 0 perguntas (S1 a S3 confirmadas pelo dono em 2026-11-05)
- **Depende de:** 060 (web só com dado real, ADR 0026), 069-lacunas-alta (lacunas de dado real em andamento)

## Escopo
- E1. Por cartão (cada métrica), não por painel inteiro: cartão com dado real mostra só o real; cartão sem dado real mostra o simulado com o selo "Simulado" no próprio cartão; quando o dado real passa a existir, o cartão troca sozinho e o selo some · `confirmado`
- E2. Uma ADR nova registra a mudança e revê a ADR 0026 (web só com dado real), sem apagar a decisão antiga · `confirmado`
- E3. O selo "Simulado" e o texto que explica o que ele quer dizer, especificados pelo UX e validados pelo dono antes do código · `técnico`
