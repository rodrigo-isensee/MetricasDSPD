## B-2: o foco
- `botaoRecolher` (CartaoMetrica.tsx:178) é a ref do botão Recolher/Expandir (:269). O Tentar de novo (:326-334) chama `focus()` antes de `onTentarDeNovo`, então o foco já está num elemento estável quando o botão some ao recarregar. O Tentar de novo só aparece com `recolhido`, que implica `recolhivel`, então o botão referenciado existe sempre que o clique é possível; o `?.` é só defesa de tipo.
- **O caso de foco no conteúdo se o cartão abrir: basta não tratar.** O Tentar de novo não expande o cartão (o estado de recolher vem das preferências e o callback só recarrega), então não há conteúdo novo para receber o foco. O Expandir é o vizinho imediato, diz o estado (`aria-expanded`) e o título do cartão; se a pessoa expandir depois, o foco já está no controle que fez isso. Tratar "foco no conteúdo" só faria sentido se o retry passasse a abrir o cartão, e isso seria decisão de UX, não deste item.
