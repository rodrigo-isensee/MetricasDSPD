## Roteiro de prova de ponta a ponta (CI ou dono; precisa de Docker)

1. `pnpm run db:reset` (derruba o volume e sobe).
2. `pnpm run db:up`. Esperado: `--wait` só volta após o init; `docker compose ps postgres` mostra `healthy`.
