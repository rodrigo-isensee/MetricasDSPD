## Design Thinking dispensado

Esta demanda foi especificada antes do pedido 005 (`docs/pedidos/005-tech-lead-upstream-main-protegida.md`), que institui o upstream com Design Thinking (empatizar, definir, idear, prototipar, validar) para toda demanda com interface. Por isso ela **não passou** por essas etapas nem por validação do usuário em protótipo: o pedido 005 dispensa o 001 (e os cartões K-005 a K-011 saíram sem upstream, ver `docs/kanban/historico.md`, 2026-10-09 18:50). O discovery com Design Thinking passa a valer para as demandas seguintes, por exemplo `docs/ux/integracao-real/` (pedido 006).
